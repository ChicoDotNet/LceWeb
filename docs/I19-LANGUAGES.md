# I19 — diagnostic localisation
ES, EN, FR, PT share a single versioned definition and answer IDs. UI uses local translations, server accepts only supported language codes and stores them in lead JSON/Table and notifications. Switching languages reloads the page (do it before answering). Spanish privacy notice remains the authoritative version; translated UI makes its language explicit. Specialist review of all translations and approved translated notices are required before advertising fully localized legal content. No automatic translation of free-text answers, no language-dependent commercial weights.
